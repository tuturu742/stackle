# Stackle

A calm, offline toy for a young child on an iPad. Pick fruit from a tree, stack it,
and place it on a puddle for a splash. There are no scores, timers, text or fail states.

Play: https://tuturu742.github.io/stackle/

## Develop

```sh
npm install
npm run dev      # also served on your LAN, so you can open it on the iPad
npm run build    # typecheck and build to dist/
```

Pushing to `main` deploys to GitHub Pages.

## Install on the iPad

Open the address in Safari, tap Share, then Add to Home Screen.
